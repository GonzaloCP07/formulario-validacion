# Validador de Formularios

Aplicación web desarrollada con React y Vite que implementa un formulario de registro con validación estricta de datos mediante la librería Zod. Los datos validados se muestran en formato JSON.

## Tecnologías utilizadas

- React
- Vite
- Tailwind CSS
- Zod

## Despliegue

Para ejecutar este proyecto en local, sigue estos pasos:

```bash
# Clonar el repositorio
git clone https://github.com/TU-USUARIO/TU-REPO.git

# Entrar al directorio
cd TU-REPO

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
